# DeeDee Studio — media

Ảnh và video do CMS tải lên cho website DeeDee Studio. **Không sửa tay trong repo này**: CMS tự commit vào thư mục `media/` mỗi khi bấm Xuất bản.

- Phục vụ qua GitHub Pages: `https://avalook.github.io/deedee-studio-media/media/<tên-file>`
- Ảnh tối đa 5 MB (PNG, JPEG, WebP, GIF); video tối đa 50 MB (MP4, WebM).
- GitHub khuyến cáo repo dưới 1 GB. Video dài nên đưa lên YouTube/Vimeo rồi nhúng, đừng lưu ở đây.
